# Card icon sources

These sources apply only to the large link-card icons. The footer icons are intentionally unchanged.

- **Gmail:** Google Workspace Gmail product page — https://workspace.google.com/products/gmail/  
  Current 2026 product SVG referenced by Google — https://www.gstatic.com/images/branding/productlogos/gmail_2026/v2/web/192px.svg  
  Stored locally as `gmail-official.svg`.

- **Instagram:** Meta Instagram Brand Resource Center — https://www.meta.com/brand/resources/instagram/instagram-brand/  
  Gradient glyph stored locally as `instagram-official.svg`, matching the approved Instagram gradient glyph.

- **PDF:** Adobe PDF file icon guidelines and hosted asset — https://www.adobe.com/legal/permissions/icons-web-logos.html  
  The resume card links directly to `Resume.pdf` and displays Adobe's hosted PDF file icon without recoloring or modification.

- **Projects:** Google Material Design Icons — https://github.com/google/material-design-icons  
  The `dashboard` glyph was selected because it visually communicates a structured collection of projects. Stored locally as `projects-icon.svg`.
